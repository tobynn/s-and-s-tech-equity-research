# 에스앤에스텍 (101490) | Equity Research

**분석 빈티지: 2026-10-17 · 실적 기준: 2026년 2분기/반기 · 통화: KRW · 단위: 십억원(별도 표기 시)**

에스앤에스텍의 투자 가치는 기존 블랭크마스크·펠리클 사업의 현금창출력과 EUV 제품의 상업화 선택가치를 분리해 봅니다. EUV 고객 테스트·센터 준공은 성장 경로의 증거지만 반복 양산 매출을 뜻하지 않으므로, 기본 가치에는 확인된 EUV 증분 매출을 넣지 않습니다.

## 핵심 관점

- 2025년 연결 매출 243.733, 영업이익 50.390, 순이익 58.093. 공식 IR 요약 재무정보 기준입니다.
- 2026년 상반기 매출은 전년 대비 +8.0%, 영업이익 -0.8%, 순이익 +20.9%로 집계됐습니다. 상반기 성장률만 연환산하지 않고, 매출 성장과 이익률 흐름을 분리합니다.
- EUV 센터와 삼성 4nm 파운드리 테스트는 기술·고객 검증의 진전입니다. 실제 양산 승인, 수율, 출하량, 단가가 확인되기 전에는 현금흐름 가치에 반영하지 않습니다.
- PER 비교는 블랭크마스크/포토마스크 소재 노출이 직접 겹치는 상장사를 우선합니다. 유사 상장사가 충분하지 않아 동종기업 평균 PER을 목표 배수로 사용하지 않습니다.

## 결과 상태

이 저장소는 재현 가능한 **시나리오 프레임워크**입니다. 다운로드 시점의 주가, 희석주식수, 순현금, 반기보고서 세부 자본·현금흐름표를 한 번에 공식 원문 대조하지 못한 항목은 공란으로 유지합니다. 따라서 주당 적정가와 매수/매도 결론을 제시하지 않습니다. `model/run_valuation.py`를 실행하면 ROIC 기반 reinvestment identity를 적용한 EV 감도표가 생성됩니다. DART 세부 CAPEX·D&A·NWC 검증 전의 proxy이며 결과는 분석자 가정이지 회사 가이던스가 아닙니다.

## 실행

```bash
python model/run_valuation.py
```

계산은 기업가치(EV) 기준입니다. 순현금, 비영업자산, 희석증권과 주식수 확인 후에만 지분가치와 주당가치로 이어가세요.

## 한계와 업데이트 게이트

1. DART 반기보고서 주석에서 제품별 매출·고객집중도·설비투자·감가상각·순현금을 다시 추출합니다.
2. EUV는 고객 승인 → 반복 출하 → 수율 안정 → 매출/마진 공시 순으로 확인하고 단계별로만 상향 반영합니다.
3. 현금흐름은 운전자본과 EUV 센터 투자 부담을 반영한 후 DCF에 연결합니다.
4. PER은 comparable set의 사업 중첩도, 마진, 성장, 규모를 함께 공개하고 배수의 출처와 관측일을 기록합니다.

본 자료는 교육·연구 목적이며 투자 권유가 아닙니다.
