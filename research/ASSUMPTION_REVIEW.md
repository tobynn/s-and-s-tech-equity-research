# [에스앤에스텍 가정 검토 | 2026-10-18 v3]

## [검토 결론]

기존 DCF·RIM·이론 PER의 Base 입력은 유지했다. 공시가 새로 발표되어 전망을 상향한 개정으로 표시하지 않는다. 이번 수정은 조건부 가치의 경제적 부담과 설명력을 점검하는 작업이다.

|점검|Base 결과(원/주)|의미|
|---|---:|---|
|기존 DCF|26,106|현재 명시 전망과 장기 ROIC 조건|
|장기 ROIC=WACC DCF|25,402|장기 초과수익 가정 제거|
|기존 RIM|19,439|전체 장부자본에 성숙 ROE 적용|
|현금 수익률 분리 RIM|13,149|장기 순현금의 낮은 수익률 분리 민감도|

PER와 RIM은 DDM과 공통 가정을 가진다. 세 평가값을 독립적인 시장 확인 자료로 세거나 평균 목표가로 사용하지 않는다. 동일 날짜 정상 EPS를 갖춘 관측 peer PER는 이번 수정에서도 미산정이다.

## [보완한 설명과 수치]

- 2031년과 2032년의 재투자율·FCFF·ROE 전환을 표로 공개했다.
- 현금 수익률 분리 RIM과 terminal RI=0 RIM을 추가했다. 영업자본의 계정별 분리 전에는 민감도로 사용한다.
- DCF 가치를 명시기간·잔존가치·순현금·비영업 자산으로 분해했다.
- 마진 -2%p, 2027~2031 CAPEX +20%의 비용 민감도를 추가했다. 분석자 스트레스이며 관측 충격 크기가 아니다.
- 참고가격을 연말에도 같다고 고정했을 때의 terminal FCFF·마진과 PER 정상 마진을 역산했다.
- 기업별 교환사채·계약 수수료·해외 성장·주주환원·금융자산/ADR 환율을 원자료와 연결했다.
- 가정별 사실·추정 구분, 필요한 추가 자료, 입력 수정 조건을 같은 표 형식으로 작성했다.
- Excel에 Diagnostics·Special Cases 수식 시트를 추가하고 Python과 3개 시나리오를 대조했다.

## [사용 범위와 남은 자료]

자료의 실제 계정과 분석자 추정을 구분한 교육용·포트폴리오용 기업분석이다. 동시점 CAPM 입력, 동일 날짜 정상 EPS의 정량 peer 집합, 거래소와 시세 공급사의 가격 차이, 실제 연말 현금·자본 거래는 아직 확정되지 않았다. 원자료가 확보되면 입력 버전을 갱신한다. 가정의 자릿수를 늘려 이 항목을 확정값으로 표시하지 않는다.
